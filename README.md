# Kejutan Ulang Tahun untuk Marlina

Halaman ulang tahun romantis dan interaktif. Buka langsung melalui `index.html`, atau jalankan server lokal:

```powershell
python -m http.server 5500
```

Kemudian buka `http://localhost:5500`.

Fitur: pembuka hadiah, lilin interaktif, confetti, kartu pesan rahasia, dan desain responsif.
